# 0.11.0 — Simulator automation and list consistency

Removed all simulator example tabs/download routes. Protocol fixtures now live under protected tests/fixtures/protocols for parser regression only. Imports and Upload SNMP Record are the remaining tabs. Sidebar and submenu rendering share templates/submenu.php.

Upload validates actual multipart .snmprec input, stages the responder data and queues automatic native provisioning. A dedicated Apache-user systemd timer verifies live sysName before creating one data source and graph for each supported numeric OID. Counter32/Counter64 use COUNTER; Integer32/Gauge32/TimeTicks use GAUGE. Text, address, OID values and LLDP/CDP identity fields are excluded. Five bounded attempts handle activation delays; failures retain the record and show an explicit retry. The uploader's current permissions are checked again by the worker. Existing provisioned imports are not recreated.

Native list links use green text; submitted actions remain buttons. Lists now include page counts, row size and First/Previous/Next/Last controls. Simple single-page tables show a compact count. Editable list pagination retains every form input, including values on hidden pages. Existing server-filtered import/device lists preserve filter values across pages.

QA: PHP syntax and strict parser tests; real multipart upload validation using a temporary loopback test server (valid record accepted, wrong extension/missing file rejected); automatic worker provisioned a controlled 11-record fixture with exactly 5 native data sources and 5 graphs; exact OID inputs and Counter/Gauge types matched, and repeated provisioning/duplicate uploads created no duplicate objects. The native Cacti poller read all five expected fixture values (123456, -12, 345678, 77, 12345678901). Browser list pagination advanced through 50 jobs and preserved an unsaved collection-interval edit. The in-app browser file chooser timed out, so the complete browser file-selection/upload sequence was not verified. The controlled QA device is retained as Topology Upload QA 0.11.0 for inspection.
