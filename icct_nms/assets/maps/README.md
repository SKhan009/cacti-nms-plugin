# Local map assets

`india-states.json` is the same bundled state/UT dataset as the NMS plugin (`css/nms-map-states.json`). It contains 36 simplified features with local English labels. It is a display dataset, not a survey.

Source: geoBoundaries gbOpen IND ADM1, boundaryID IND-ADM1-1811400, pinned release 9469f09; DataMeet India community / Election Commission of India. License: CC BY 2.5 IN (https://creativecommons.org/licenses/by/2.5/in/). Attribution is displayed on the map. Source metadata: https://www.geoboundaries.org/api/current/gbOpen/IND/ADM1/ .

Leaflet 1.9.4 and its license are bundled in `assets/vendor/leaflet`. Basemap images use the existing NMS GeoServer configuration, through ICCT's authenticated WMS endpoint. No external tile or font service is used.
