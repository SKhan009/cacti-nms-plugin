Port Config

Physical port count comes from Device Type presets. Actual interface names and link status come from the device. In use means link up; Available means enabled with link down, which does not prove the port is unplugged.

Only discovered interfaces are shown. The preset count is expected capacity; it does not assign interface names or link status.

Fault thresholds

Select an associated graph template and data source. A value below Minimum or above Maximum raises the selected severity; values equal to a threshold stay Normal. Add multiple rules for different severity levels.

Thresholds use the stored data source’s AVERAGE values before graph CDEF/VDEF transformations. Template data limits populate new rules where defined; review them before saving. Blank means no bound.

Polling interval: 300 seconds (inherited from Cacti). Template data limits are suggestions, not alarm thresholds.

Email and Audio preferences are saved with each rule. Notification delivery is not active yet; selecting these options does not send email or play an alarm.
